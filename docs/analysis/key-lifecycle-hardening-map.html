Key Lifecycle Hardening

6. Who is affected

Read from the sibling repositories on 2026-11-18; none is edited from here.

SSIoBC-vclaim

Nothing changes. It validates with 0, on an active DID.

SSIoBC-trust

Three integration tests change when it moves its pin: test_openCallerKey_outlivesTheKeyThatNamedIt, test_reactivateDid_longLivedKeyReactivates, and test_openCallerKey_stopsWhenTheDidLapses (it keeps passing but tests nothing). Threat model rows T5 and T6 are rewritten.

Integrators of keys longer than a year

Keys validated for more than a year are now stored as 365 days. The clamp is silent: read the stored value with getExpiration.
